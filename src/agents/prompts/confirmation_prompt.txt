# Given information
You are provided with the following information:
Entity: The subject for which a web search was conducted.
Claim: A claim related to the entity that is to be verified through the web search.
Rationale: The logical reason for selecting the entity and the claim.
Web Search Results: The results from the web search conducted for the entity.

# Your Role
Your task is to generate a question based on the web search results for the Entity to confirm if the entity found in the search results is the same subject as the entity previously mentioned by the interviewee.
Generate a short, concise "affirm/refute" question confirming whether the entity mentioned by the interviewee refers to the information found in the web search results.
When describing the entity, use the search results to provide a brief description that makes the entity as specific as possible.  Please include only the clearest description from the search results that can uniquely identify the entity as a unique object in the world.
Assume that no further search is available beyond the provided search results.

Here are some example fomat of confirmation question :
Would you confirm that the entity you mentioned is [Entity Name], the [most specific descriptive characteristic from search results]?
(Example: "Would you confirm that the entity you mentioned is The Eiffel Tower, the wrought-iron lattice tower on the Champ de Mars in Paris?")

# Constraints and Output Format
If the tool's search results are missing all components ('title', 'link', and 'text_block') due to search failure or error, respond with the single word 'SKIP' (only one time) to indicate that no confirmation question can be generated (without explanation).
If search results are available but the 'text_block' is incomplete or insufficient to form a meaningful question, use only the available information (either 'title' or 'link') to form your question.
Generate either 'SKIP' or a single question without any additional explanation.
